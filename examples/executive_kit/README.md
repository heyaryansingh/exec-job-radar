# Example executive kit (fictional)

What `tools/kit/build_latex.py` produces from a `kit.json`: a tailored executive resume and
cover letter, a PNG of every page for the visual review, and `review.json`.

"Jordan Lee" and every employer, number and fact here are invented. This is a reference
for layout and level of detail only. A real candidate's kit is written from their own
documents during setup (ONBOARD.md, Step 3), and the builder refuses to pass a kit that
still contains text from this example.

Rebuild it: `python tools/kit/build_latex.py examples/executive_kit/kit.json examples/executive_kit`
